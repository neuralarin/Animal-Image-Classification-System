# 🐾 Animal Image Classification System

A simple deep learning project that classifies an uploaded animal image into its corresponding category using a **PyTorch CNN** and a **Streamlit** web application.

## 🧠 What I Learned

Through this project, I learned how to:

* Work with an **image classification dataset**
* Perform **image preprocessing and resizing**
* Build a **CNN (Convolutional Neural Network)** using PyTorch
* Train and evaluate a deep learning image classification model
* Use **PyTorch tensors and DataLoaders**
* Save and load a trained model using `.pth`
* Make predictions on new images
* Build a simple **Streamlit UI** for image upload and prediction
* Connect a trained deep learning model with a web application

## 🛠️ Tech Stack

* **Python**
* **PyTorch**
* **Torchvision**
* **PIL**
* **Streamlit**
* **Jupyter Notebook**

## 🔄 Project Workflow

**Image Dataset → Preprocessing → CNN → Model Training → Evaluation → Model Saving → Streamlit Prediction**

## 🚀 Streamlit Application

The application allows users to:

1. Upload an animal image.
2. Preview the uploaded image.
3. Get the model's predicted class.
